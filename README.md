## 🚀 Overview

**Chrysus Digital** is a cutting-edge web platform and B2B SaaS solution engineered to help businesses eliminate missed opportunities through 24/7 autonomous Greek AI receptionists, automated CRM workflows, and ultra-fast custom web apps. 

Built using the **Next.js App Router**, **Tailwind CSS v4**, and **Framer Motion**, the platform features a sleek dark-mode minimalist vignette design system optimized for top-of-funnel conversion workflows, interactive client onboarding flashcards, and flawless Core Web Vitals performance.

---

## ✨ Key Features

* **🤖 AI Voice Agents & Automations:** Showcasing 24/7 automated call handling, request triage, and business CRM integrations.
* **⚡ Interactive Flashcard Funnel:** A custom multi-step client onboarding flow (`ContactFlashcards`) built with smooth layout animations, live input validation, and secure **Web3Forms** API submission.
* **🖼️ Immersive Visual Integration:** High-performance background asset integration (`next/image`) with multi-stage dark vignettes and seamless transitions between sections (`bgimg.jpg`, `processbg.jpg`, `contactbg.jpg`).
* **🔍 Advanced SEO & Crawlability:** Fully configured `app/robots.ts` and dynamic `sitemap.xml` rules ensuring proper indexing without rendering regressions on `/_next/` assets.
* **♿ Accessible & Responsive:** Rigorously structured semantic HTML (`<main>`, `<article>`, `<nav>`) with complete keyboard navigation and screen-reader support.

---

## 🛠️ Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router, Server & Client Components)
* **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
* **Animations:** [Framer Motion](https://www.framer.com/motion/)
* **Icons:** [Lucide React](https://lucide.dev/)
* **Forms & Backend:** Web3Forms API & Supabase Authentication Integration
* **Language:** TypeScript
